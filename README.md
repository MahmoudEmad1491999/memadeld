# Mahmoud Emad-Eldeen — Embedded Software Portfolio

A lightweight, responsive, single-page portfolio website built with plain HTML and CSS. It has no build step, JavaScript framework, external font dependency, analytics, or third-party runtime assets.

## Preview locally

Open `index.html` directly in a browser, or serve the folder locally:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

1. Create a repository for the portfolio (for example, `mahmoudemad1491999.github.io`).
2. Copy `index.html` and `README.md` into the repository root.
3. Push to GitHub.
4. In **Settings → Pages**, select deployment from the `main` branch and `/ (root)`.

## Content maintenance

The project summaries intentionally distinguish implemented work from roadmap items. Update the project cards as the repositories evolve—especially the current status/roadmap sections—so the portfolio remains an accurate snapshot rather than implying the projects are finished.
